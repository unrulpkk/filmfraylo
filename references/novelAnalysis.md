# 小说全书分析

先遵循 [FilmFraylo](../SKILL.md) 的连接和本地交付约定；执行者是 当前 Harness，通过官方 MCP 读取与保存，禁止委托内置 Agent。

1. 从工作区盘点原文的文件、编码、章节边界和版本。按章节分批读完整正文；读取截断时以真实偏移续读。建立覆盖表：文件、章节/段落起止、已读区间、下一偏移、缺页/乱序。PDF 等无法读取时说明所需文本转换，不能凭书名补全。
2. 每批提取事件卡：章节位置、人物目标、选择与行动、阻碍、转折、结果、时间地点、因果前提。区分叙述顺序与故事时序。将原文证据定位到章节及短引文，避免在报告中重复整本原文。
3. 累积角色别名索引、关系变化、世界规则、关键道具、伏笔铺设/回收/未解表。后文信息可修正先前推断，但保留证据和修订记录；不要将后文知识提前赋给前期角色。
4. 完整覆盖后综合主线/支线、人物弧光、核心冲突、高潮与结局，提出适合漫剧的视觉事件、难以直接呈现的心理段落、可合并事件和必要保留因果。篇幅、集数和改编幅度沿用用户要求；缺失时给带假设的建议，不冒充定稿。
5. 用官方文件工具保存 `analysis/bookAnalysis.md` 与覆盖记录；用文本节点函数可将结论摘要放入指定画布，正文较长时保留文档路径。只有所有约定章节均读完才标记“全书完成”，否则报告覆盖比例及缺项。

交付必须能回答：主人公为何行动、每个关键转折由什么造成、删减会破坏哪些因果、哪些悬念必须保留到哪一集。不能只列题材标签和剧情流水账。将待确认改编与原著事实分栏，供角色和分集阶段引用。
