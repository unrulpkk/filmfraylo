# 人物提取与角色档案

先遵循 [FilmFraylo](../SKILL.md)，读取原文覆盖记录、当前剧本和已有角色档案；Codex 直接通过官方 MCP 执行。

按姓名、别名、称谓和证据合并同一人物，不凭同姓合并。为每个人物建立稳定 C 编号，标记首次出现、有效章节/集数、别名、身份、叙事功能、目标、恐惧、矛盾、行为习惯、关系和变化节点。区分读者已知与角色已知信息，避免提前泄露秘密身份。

每条外形/声音信息标注原文出处；原文未写的年龄、性别、体貌或服装不能伪称原设。必要的视觉设计以“改编设计”单独列出：脸型、发型、身形、标志物、服装层次与材质、色板、姿态；声线记录音色、语速、口音和情绪边界，不虚构模型的 voiceId。

角色档案区分恒定特征与集内状态：换装、伤势、年龄阶段、随身道具、情绪起点/终点。对核心人物给出可观察的表演方式，避免抽象人格词堆砌。关系表保留方向、关系生效范围和证据；冲突信息登记为待核实。

通过官方文件工具保存 `characters/C001.md` 等档案和角色索引，使用节点函数建立或更新相应文本节点；先找既有节点，保留其 ID。已批准的参考图用实际文件/素材节点关联，记录模型、提示词、版本及采用状态。图像制作进入 [mediaProduction](mediaProduction.md)，文字档案完成不代表角色图已生成。

交付核对：别名无重复身份、每个主要人物有行为动机、证据可追溯、状态不会跨集错误继承、未定设计明确标记。
