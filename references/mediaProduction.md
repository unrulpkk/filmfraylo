# 图片、视频与配音生产

先遵循 [FilmFraylo](../SKILL.md) 和官方 Toonflow MCP Skill。当前 Harness 负责执行；沿用已授权的模型、数量、规格和批次，不启动内置 Agent。

## 从计划到真实节点

调用媒体模型前，遵循 [Key 与充值引导](../SKILL.md#api-key-与充值引导)：无 Key 时引导用户在本地网页填写；供应商明确提示余额不足时链接到 https://api.safillu.com 充值。配置或充值后核对任务状态，再继续未完成的生成。

读取本批镜头、角色版本和已有任务状态。通过现有模型列表和 getNodeTools 获得真实 providerId/modelId、比例、分辨率、时长、声音和 voiceId 选项；无配置时报告缺项，不伪造可用模型或绕过供应商。展示具体批次及算力消耗信息（不可查时写未知）；用户已授权的同一方案直接执行，超出范围时只确认差异。

图片先固定角色/场景资产，再生成需要的镜头图；视频按模型支持的文生、首帧或参考模式接入真实输入；配音保持角色声线、对白、语速、停顿与情绪一致。模型原生声音是否可用以 schema 为准，不一律额外生成配音。Seedance 提示词遵循已安装 workflow 的对应规范。

复用现有节点，必要时 addNode。参数通过节点公开函数写入；引用通过真实端口连线，核对 referenceOrder 与提示词标记。启动后保存任务/node ID、完整提示词、模型、参数和引用版本，再用 node:getGenerationStatus 查询。generating 只代表已开始；超时先查询，不重复提交。不支持状态查询时明确说明，不能把再次生成当查询。

## 本地保存与网页验收

成功后读取节点 outputs 中的真实相对路径；生成服务原生保存到工作区，无需另造下载服务。用 workspaceFiles 确认文件存在及非空，图片/视频/音频由现有素材节点或原生文件预览打开。临时供应商 URL、磁盘路径、已生成和已验收是不同状态。

- 图片：网页请求成功且 Content-Type 为实际图片类型；浏览器图像解码成功、有非零宽高，并检查画面和角色一致性。
- 视频：网页 video loadedmetadata 成功，尺寸/时长非零，能播放并拖动定位；必要时确认现有文件接口的 Range 请求返回 206 与正确 Content-Range。HTTP 200 本身不代表视频可解码。
- 配音：网页 audio 可播放、时长合理；检查缺字、读音、声线与对白同步。浏览器格式不支持时使用现有媒体/FFmpeg 能力产生兼容副本，保留原件，不修改文件 API。

没有浏览器或媒体读取能力时记录“文件已保存，预览未核验”，不声称完整验收。测试素材只能证明链路，不冒充真实供应商生成。失败记录阶段、错误和可恢复状态；已完成素材不重复生成。

将输出路径、实际规格、网页读取/播放结果及用户采用状态写入 productionState.md。连续镜头等待前镜结果和交界状态后继续；保留候选与已采用版本。交付时清楚区分已配置、已开始、已保存、网页已验证和用户已采用。
