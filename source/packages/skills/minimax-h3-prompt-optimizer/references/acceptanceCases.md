# H3 Agent 技能验收场景

这些场景用于维护和行为回归；测试素材不代表用户作品内容。每次验证区分静态文件检查、真实 Agent 行为与真实视频效果，不能把规则存在或文字通过当成视频已生成。

| 场景 | 核验结果 |
| --- | --- |
| 1. 产品文字需求，无素材 | T2VA，官方三字段，不编造对白/配乐 |
| 2. 自然场景，一张明确首帧 | I2VA，首帧对齐 0 秒并向后发展 |
| 3. 动画首尾帧各一张 | FL2VA，按实际首尾角色排序并有中间过程 |
| 4. 真人动作，仅尾帧 | L2VA，最终镜头与有效结束时间正确 |
| 5. 一张角色图和音色参考 | Ref2VA，六字段，音色明确绑定且不复制未知台词 |
| 6. 多图分别提供人物、环境、服装、表情 | 类别内标签稳定，各自用途/保留关系清楚 |
| 7. 一图多人和场景 | 允许多个 Subject 来自同一 Picture |
| 8. 多角色不同语言对话 | 按首次实际发声编号，语言/原文/人物/音色不串位 |
| 9. 没有台词和音乐要求 | 无新增对白，non_diegetic_music 为 N/A |
| 10. 指定缓慢向左平移机位 | 机身平移与原地摇镜区分，必要方向/幅度/速度明确 |
| 11. 保持角色和场景，只改动作 | 外观/背景连续，变化仅作用于指定属性 |
| 12. 连续复杂物理运动 | 初始支撑、运动过程、节奏和结束态完整，不跳过关键接触 |
| 13. 5 秒内给出明显过长完整台词 | 保留全文并提示时长冲突，不删词或默默截断 |
| 14. 超过数量/时长限制，或模式与素材冲突 | 具体报冲突，不忽略素材，不承诺已经可执行 |
| 15. 重新生成或重排输入描述 | 既有真实来源/标签/角色映射稳定 |
| 16. 模型/工具失败或校验未通过 | 原 prompt 保留，不写空值或半成品 |
| 17. 用户已手动修改正文 | 优化基于当前版本；仅请求保存时写回现有文本/视频节点 |
| 18. 保存重开后继续 | 读取实际已保存 prompt、参数、映射和状态，保留原编号 |

增强格式另核验：只在用户选择时启用；scale_and_continuity 标明自定义；retention_analysis 可选；Base 组合冲突明确提示。未知音频内容不得被“自动识别”，素材文件或时长读取不构成视听内容验证。
