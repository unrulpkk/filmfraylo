# 通用增强格式与可复用结构

此文件保留旧路径以兼容已有引用，内容适用于任意题材。它不是固定人物/剧情的短剧模板。

## 官方默认

Base 与 Ref2VA 默认分别使用三字段和六字段官方格式，见 [格式规范](h3-format-spec.md)。不能在官方字段间插入自定义章节，也不强制添加人物、对白、配乐或多镜头。

## 可选实战增强

仅当用户选择“增强格式”且模式为 Ref2VA 时使用，字段顺序为：

1. subject_definitions
2. scale_and_continuity
3. summary
4. retention_analysis（用户选择保留时包含，否则省略）
5. detailed_description
6. overall_soundscape
7. non_diegetic_music

scale_and_continuity 是 FilmFraylo 自定义扩展，**不是 MiniMax 官方原生字段**。在 prompt 之外明确所用格式，不能把说明标题写进 prompt。

该字段集中记录实际时长/画幅、人物比例、左右关系、构图、背景衔接、服装道具、光线色彩和自然运动等已要求的约束。缺失的可选约束不补写，避免与正文重复。其余字段仍遵守官方标签、说话者、时间与声音规则。

用户要求 Base + 增强时指出格式不适用，提供恢复官方 Base 或改用合法 Ref2VA 的选项，不能把素材含义偷偷改成另一模式。

## 优化已有文本

以用户当前手动编辑版本为基线，保留未经要求修改的动作、台词、绑定、风格、连续性与音乐选择。只修复已确定的结构错误；格式修复最多一次。遇到角色/台词归属或首尾帧身份不明等语义问题先提示，不用第二套模板重写全部内容。

最终只输出已替换全部变量的 H3 正文，临时结构提纲、JSON、方括号占位说明和教学案例均不进入交付。
