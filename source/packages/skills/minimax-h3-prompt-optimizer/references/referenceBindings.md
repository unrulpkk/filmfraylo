# 素材映射与声音绑定

## 映射记录

为每个实际素材保存来源标识/真实附件或节点句柄、类别、类别内编号、用户指定用途、关联主体、保留关系；音视频还记录真实时长和已知读取能力。既有映射优先，第一次分配后不因重排描述或重试改变素材身份。

图片 <Picture N>、视频 <Video N>、音频 <Audio N> 独立连续编号；可复用内容用 <Subject N>。一个图片可定义多个人物与环境，一个主体可综合外观图、服装图与动作视频；不能按第几个连线猜第几个角色。真实附件顺序必须与各类别编号一致。断开、删除或替换素材时同步更新定义、引用和实际附件顺序，不能让同一标签指向另一份文件而不更新。

主体在内部分配稳定 key，重新生成保留既有身份 key 与编号。用户明确的角色名称用于绑定，普通物体名称在英文正文中翻译；不要把所有用户中文描述当作不可翻译的专名。

未知或仅口头描述的媒体可以参与提示词规划，但注明尚未读取/验证；实际生成前必须核对文件、节点和接口支持。没有实际资源时不能虚构已连接的素材句柄。

## 用途和保留

- Picture 可以是首帧/尾帧/具体帧锚点，也可以只提供身份、服装、道具、环境、构图、光线或风格。两种角色明确区分。
- Video 可以提供主体动作、节奏、镜头运动、剪辑结构，或作为直接编辑/续接源。其包含声音不自动创建 Audio 标签；确实使用音轨时才单独定义音频用途及来源。
- Audio 区分音色、语速/节奏、情绪、音乐风格、音效纹理、原始信号复用。一个素材多用途可以合并说明，不编造它的原始台词。
- 视觉保留标记：fully_preserved、partially_preserved、attribute_transfer、weak_reference。
- 音频标记：fully_copy、partially_copy、reference、weak_reference。
- 完全保留仅针对已定义的参考作用，不代表禁止本次新动作；属性迁移写清来源属性与目标主体。部分改变写明变化内容。音色 reference 不等于复制信号；增加/替换声音层时不能称为完整整轨 fully_copy。

## 说话者

(S1)、(S2) 按目标视频第一次实际发声的顺序分配，后续保持一致。Subject 编号与 Speaker 编号不要求相同，未发声的可见角色没有 Speaker ID。

只有用户明确给出声音与角色关系时，才把 <Audio N> 绑定到对应主体/说话者；角色同名歧义时先澄清。一个音频用于多个角色须由用户明确指定。不能从接线顺序、文件名或“女声/男声”猜人物身份。

subject_definitions 同时给出素材角色、主体来源与必要声音绑定；summary 复用这些已定义标签；retention_analysis 保持相同用途，避免塞入说话者编号或重定义角色；detailed_description 在实际生效点使用正确标签。检查台词原文、语言、声音身份与当前画面中的发声者一致。

FilmFraylo 当前 Agent 是否能读图、视频或音频，取决于所用模型和宿主工具。音频最低保证为标签、用途和明确绑定；没有实际语音识别工具时不转写、不虚构内容。读取时长、播放地址或容器参数不代表“听过”。用户明确提供的文字转录才可作为台词来源。
