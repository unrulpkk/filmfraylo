# 通用动作、镜头与连续性规划

面向真人、动画、产品、自然、纪录片、科幻等任意合理题材；不预设性别、人物、服装、年代、剧情、场景或视觉风格。保持用户意图，把抽象目标转换成有依据的可见变化，不能把这份方法当成新增情节的授权。

## 内部场景计划

保留这些可选信息即可，不要求用户补表：
- 目标、风格、时长/画幅、初始状态、必须达到的结束状态。
- 每个主体的位置、动作执行者/承受者、道具接触关系。
- 必须保持的身份、比例、左右、服装、道具、背景、光线、色彩；明确允许变化的内容。
- 用户原文台词/歌词、说话者、语言、是否画外音/演唱、音色参考。
- 素材映射、通道限制、来源未知项、上一镜头真正已确认的结束状态。
- 精简/标准/详细与用户补充修改；已有 prompt 的当前编辑版本。

未知细节可以用保持素材原样的表达，不编造年龄、性别、脸型、材质、装饰、参考画面内容或音频台词。涉及关键语义歧义时提示具体疑点；物理/剧情冲突不能通过删改原需求偷偷消除。

## 动作与镜头

每个主要动作考虑起点、接触/支撑、运动路径、节奏、结果和必要反应。复杂物理动作写中间状态、重心或动量变化，主体/道具移动先后清楚；只补实现已定动作所需的执行细节，不新增事件或道具来源。

表情/情绪通过已有场景支持的目光、姿态、呼吸或表情变化呈现，适量选择，不给所有角色机械套用同一串微动作。没有情绪要求的产品或自然场景不强加“演员反应”。

写明景别、构图和必要机位空间关系；运镜包括动作方向、有意义的幅度和速度。镜头跟随主体、机身平移、原地摇镜、变焦和环绕分别选择，不堆标签。连续行动优先连贯呈现，切镜要提供新信息，不强制 one continuous shot，也不强制一句一镜。

## 时间与对白

在目标时长内按实际动作需要安排节奏，不机械均分。短片减少无关动作和切镜，不能通过删原台词、跳过关键动作来满足预算。对白明显太长时完整保留，单独说明需要延长/拆片的冲突；未获用户同意不能把完整台词改成截断或概述。

多个角色按真实说话顺序组织，区分讲话、聆听反应、旁白与歌词。音色参考不代表复制源音频的原话。未指定对白时不编造，也不自动把用户需求叙述当作人物台词。

## 保持与变化

将 preserve/change 分别落实到每个有关主体和镜头，禁止同一属性既要求完全保留又无说明地变化。跨镜头延续实际左右关系、手中道具和衣着状态；机位变化后背景应与空间关系相符。前镜尚未生成/采用时，预期结束状态只能作为规划，不能声称已验证真实衔接。

用户修改时只重做受影响的规划、引用或声音关系；保留未修改内容、现有主体 key 和真实素材映射。先完整生成候选再替换，生成失败保留旧版。

## 交付

精简保留可执行核心，标准覆盖完整必要过程，详细补充有依据的中间状态与连续性。只输出选定格式的 H3 正文；模式说明、限制和警告在正文之外。只写提示词时不创建素材或调用视频生成；写入现有节点时按宿主公开函数与实际输入连接核对。
