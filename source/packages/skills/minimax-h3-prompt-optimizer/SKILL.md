# FilmFraylo · MiniMax H3 提示词规划

这是 FilmFraylo 内置 Agent 的技能插件。Agent 直接理解、规划、撰写与校验提示词，复用当前对话的语言模型；不需要提示词生成节点、额外模型调用、独立服务或 Key。只请求提示词时直接交付文字，不创建画布节点、不生成视频。

## 入口与材料

- 用户明确要 H3 提示词时直接使用本技能。需要实际视频生成时，先用当前模型列表和目标节点能力核实供应商、模型、时长、参考模式和声音；支持新 H3 衍生型号，不把名单写死。未确认模型的普通视频任务先发现实际候选，不默认 H3 或 Seedance。
- 自然语言、小说、剧本、分镜、已有 prompt 都可作为输入。默认目标为 5 秒、16:9、官方格式、标准详细度；已有明确参数优先。风格、人物/场景/道具、动作/情绪、镜头、台词/语言/音色、音效/音乐、保持/变化、前镜连续性均可选。
- 空字段不强行补内容；从当前输入能合理推断的细节直接处理。缺少决定模式的首尾帧角色、音色绑定等必要信息时，只澄清该缺项，不要求填写整张表。
- 英文撰写提示词正文。用户的台词、歌词、画面文字和真正的专名保持原文；普通中文名词应译成英文，不把“白色杯子”当成专名。
- 不增加用户未要求的人物、剧情、对白、歌词或配乐；不把任何参考案例的内容套进作品。

## 规划流水线

内部完成以下步骤，不把分析过程或内部 JSON 混进最终 prompt：

1. **理解意图。** 提取目标、初始状态、主体与环境、动作结果、镜头、声音、明确保持/允许变化和前镜连续性。用户原文与推断分开；冲突用提示报告，不静默改剧情。
2. **建立素材映射。** 按 [参考绑定](references/referenceBindings.md) 记录真实来源、类别、稳定标签、用途、主体和保留关系。没有被实际读取的素材只依据用户说明，不能声称看过或听过。
3. **判定模式并校验边界。** 自动判断默认模式，也尊重用户手动指定；按 [格式与约束](references/h3-format-spec.md) 拒绝不兼容组合，不忽略额外素材，不把普通参考图当实际首帧。
4. **组织动作和时间。** 按 [动作与镜头规划](references/action-expression-playbook.md) 写起点、物理过程、节奏、结果与反应，按真实动作安排时长，不平均切段、不强制每句台词切镜。连续动作优先连贯呈现，必要切镜才引入新信息。
5. **绑定对白和声音。** 原文逐字保留；按首次实际发声顺序建立稳定说话者编号，音色按明确角色绑定，区分对白、画外音、歌词、环境声和配乐。过长对白警告并保留全文，不擅自删改。
6. **选择并渲染格式。** Base 用三字段与实际首尾帧对齐指令。Ref2VA 完成规划后、开始写成品前读取 [英文输出协议](references/refFormat.md)，按官方六字段直接写英文正文。只有用户选择增强格式才读取 [增强格式](references/short-drama-templates.md)，其中 scale_and_continuity 明确为自定义字段。
7. **独立核对后交付。** 按下方验收项核对。可确定的格式错误最多修复一次；不确定的语义冲突单列提示，不把猜测当修复。失败保留上一版，不能用空内容或半成品覆盖。

## 交付验收

- 模式、字段顺序、标签、实际首尾帧和结束时间对应正确；引用全部有定义，素材顺序与真实附件一致。
- 镜头编号与切镜时间合法，目标时长内连续发展，最终状态落在真实结束点。
- 所有用户原文对白、歌词、画面文字完整；说话者、语言、音色和人物对应正确，旁白不被改成张嘴讲话。
- 动作/镜头具有可见过程；人物比例、左右关系、服装、道具、光线、背景和前镜状态没有无故改变。
- 未新增无关人物、剧情或音乐；保留/变化条件不互相矛盾，未知素材细节保持未知。
- 成品只含当前格式的 H3 文本；无 JSON 包裹、代码围栏、教学说明、无关标题、未替换占位符或不存在的引用。必要诊断另列在 prompt 之外，不写入视频节点提示词。
- 仅交付提示词时，最终回复直接从当前模式的对齐指令或第一个标准字段开始，不在正文外加标题、引用块、代码围栏或“中文要点”。
- 精简只保留必要可执行内容；标准追求信息密度；详细增加有依据的过程与连续性。长度随任务复杂度变化，不凑固定字数。
- 优化基于用户当前编辑版本，保留未要求修改的内容与映射。仅在用户要求写入时，完成校验后使用真实文本/视频节点的公开函数保存；沿用原节点与旧结果，不新建专属提示词节点。视频生成仍遵守工作流已有授权和真实状态规则。

维护时用 [18 项验收场景](references/acceptanceCases.md) 检查覆盖；它们是行为验收输入，不是可复制进用户作品的故事模板。

安装维护时，可将 [H3 入口规则](references/agentRouting.md) 合并到 FilmFraylo 自身的“个性化 → 全局协作规范”，保留原内容，用于无需用户点名技能的 H3 任务入口。该规则随 FilmFraylo 数据目录保存，升级保留；技能正文仍按实际目录读取，不复制到系统模板里。
