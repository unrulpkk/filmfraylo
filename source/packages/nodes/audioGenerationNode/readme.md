# 音频生成节点

根据提示词、文本及可选的参考图片或音频生成音频。模型列表来自媒体模型设置，仅显示音频模型。

## Safillu AI

- 从文本节点输出端拖线到空白处，选择「音频生成」，或直接添加音频生成节点。
- 选择「Qwen3 · 音色设计」，输入朗读文本（也可连接文本节点），单独填写音色描述并调整 0.5–2 倍语速。音色描述与参数随画布保存，复制节点即可复用。
- 选择「YuE2 · BGM 背景音乐」，输入音乐风格描述并设置 1–120 秒最大时长。成品时长由上游决定。
- 这两个模型只接收文本，输出格式由上游决定，因此不显示不受支持的语种、采样率和格式设置。
- 生成音频可连接 H3 视频节点的混合参考输入。停止生成只停止本地等待，不会取消已提交的线上任务。

## 使用方法

1. 选中节点，选择音频模型并输入文本或音频效果描述。
2. 按需连接参考节点。文本数量不限；图片和音频互斥，合计最多连接一个。
3. 打开生成设置，选择中文或英文、采样率及输出格式；具体支持范围由供应商校验。
4. 点击生成，需要中止时点击停止；失败或取消会保留已有输出。
5. 生成后可播放、下载、截取、变速或替换音频，与普通音频节点使用相同操作。

截取和变速会在右侧生成新的普通音频节点，需要启用音频节点插件。PCM 等浏览器不支持的格式仍可下载。
