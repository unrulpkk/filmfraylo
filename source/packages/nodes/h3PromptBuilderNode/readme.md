# H3 自然语言整理

FilmFraylo 文本节点插件，使用已配置的 DeepSeek 将自然语言整理为 H3 英文提示词，同时保存对应中文。输入停止变化 1.2 秒后自动转换，也可手动重试或停止。保留对白原文、参考素材编号、指定时长和镜头要求；不调用视频生成。

输入和输出均为文本。下游必须是具有文本输出的文本节点；直接接入图片、视频等输出节点的连接会被拒绝。推荐连接 `H3 中英提示词 → 视频生成`。H3 中英提示词会复用中英文结果，显示中文、FilmFraylo 英文、H3 原生英文三个标签页；普通文本节点只接收英文。

本节点接入 H3 中英提示词节点时，显示上游中文和对应英文，直接复用已有结果；反向接入同样支持。两个方向都不会重复翻译，环形连接会被拒绝。

普通输出使用 `参考图1` 等 FilmFraylo 语法，不输出 JSON、双语拼接或内部元数据。对白、参考编号校验失败时不发布新结果，输入和旧结果记录保留。节点保存于画布，Key 继续由现有语言模型提供商管理。
