# H3 自然语言整理

FilmFraylo 文本节点插件，使用已配置的 DeepSeek 将自然语言整理为 H3 英文提示词，同时保存对应中文。输入停止变化 1.2 秒后自动转换，也可手动重试或停止。保留对白原文、参考素材编号、指定时长和镜头要求；不调用视频生成。

输入和输出均为文本。右侧中文出口接入 `H3 中英提示词` 的中文输入，明确对应第一个“中文提示词”标签；英文出口接普通文本节点，只传英文。中文出口不能接普通文本、图片或视频节点；英文出口也不能直接连接视频等非文本节点。原有英文出口到 H3 中英提示词的连线保留兼容，仍读取对应中文，不破坏已有画布。

本节点接入 H3 中英提示词节点时，显示上游中文和对应英文，直接复用已有结果；反向接入同样支持。两个方向都不会重复翻译，环形连接会被拒绝。

两个文本出口均使用 `参考图1` 等 FilmFraylo 语法，不输出 JSON、双语拼接或内部元数据。对白、参考编号校验失败时不发布新结果，输入和旧结果记录保留。节点保存于画布，Key 继续由现有语言模型提供商管理。
