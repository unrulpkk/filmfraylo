# H3 中英提示词

FilmFraylo 文本节点插件。三个标签页分别显示中文、FilmFraylo 英文和 H3 原生英文。内部从当前语言模型列表中选择已配置的 DeepSeek，输入停止变化 1.2 秒后自动翻译，也可手动转换或停止。

唯一文本输出始终是已完成的 FilmFraylo 英文，引用写作 `参考图1`、`参考音频1`、`参考视频1`；H3 原生标签中的 `<Picture 1>` 等只用于查看或复制。对白 `<d>` 中的原文保留，媒体编号转换不调用模型。主体编号不变。

连接 H3 自然语言整理的输出时直接复用中英文，不重复调用模型。连接其它文本时翻译其内容。输入或模型改变后暂时清空下游输出，完成校验后才发布新英文，失败时保留之前的结果记录供原输入恢复使用。节点文本与结果随画布保存，不存储 Key。

素材本身需另外连接视频生成节点；文字中的参考编号须与视频节点实际图片、音频、视频各自的顺序对应。本节点只读取文字，不假称已经识别图片或音频。H3 结构参考用户提供的主体定义与分镜案例，已结构化的其它 H3 提示词保留原结构。
