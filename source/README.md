# FilmFraylo

<img src="docs/images/logo.png" alt="FilmFraylo" width="120" />

**连接 AI Harness 与影视创作画布，让创意变成可查看、可调整的成果。**

FilmFraylo 是配合 AI Harness 使用的本地影视创作工具。你在 Codex、Claude Code、Cursor、OpenCode、Gemini CLI 或 WorkBuddy 中提出创作要求，由助手规划和执行，在 FilmFraylo 画布中查看和调整结果。

## 对话创作，画布呈现

AI 助手帮助你构思创意、设定角色与场景、编写剧本和设计分镜；无限画布承载镜头与素材，让你能直观看到制作进展。图片、视频和配音可以在项目中生成、预览并继续修改。

- **减少重复交代：** 沿用角色档案、剧本和已确认的创作方向，接着推进下一阶段。
- **方便局部调整：** 针对某个角色、场景或镜头提出修改，逐步打磨作品。
- **保留创作成果：** 项目资料与素材保存在本地，方便整理和后续制作。

## 开始你的项目

先按 [安装与使用](../README.md#开始使用) 为 AI 助手安装 FilmFraylo Skill，然后描述创意，或提供已有剧本、参考素材和本次想完成的目标。例如，在 Codex 中发送：

```text
$filmfraylo 请打开画布，我想做一支雨夜城市主题的科幻短片，先整理视觉方向和开场分镜。
```

使用时保持 FilmFraylo 窗口或网页打开。可以先完成创意方案、剧本和画布整理；需要生成图片、视频或配音时，再配置媒体服务 Key。
