# 小说改编分集剧本

先遵循 [FilmFraylo](../SKILL.md)，读取指定范围原文、全书分析、人物档案和已有定稿。Codex 创作并通过官方 MCP 保存，不调用内置 Agent。

确定改编范围、单集时长、目标集数、受众、画幅与忠实度。缺项可提出带假设的方案；已有明确授权直接采用。先做分集事件表：E 编号、原文章节、当集目标、主要冲突、转折、结局/钩子、角色与场景、预计时长。悬念来自实际因果，避免每集机械套同一节奏。

逐场剧本使用场号、内外景、地点、时间、出场角色、可见动作、可听对白和声音。心理叙述转换为动作、反应、环境或必要旁白；新增对白明确列入改编对照。对白标注说话人及有必要的意图/停顿，少用无法表演的解释性形容词。检查一场是否改变信息、关系或局势，冗余场景提出合并理由。

按实际台词长度、动作和停顿估算时长，并标记这是估算，不用字数机械等同片长。每集给出：开场接续、关键情绪转折、悬念/回收、下一集承接、制作资产需求。核对人物知道什么、关键道具在谁手里、时间地点是否矛盾。

保存 `episodes/episodePlan.md` 和 `episodes/E001.md`；改编对照列出原文位置、保留/删并/新增、原因和影响。已定稿内容修订另存版本或遵循用户覆盖指令；打开中的文档用 expectedText 防止覆盖。需要画布展示时，通过文本节点函数写入对应集的剧本，记录实际 textPath。

完整交付后将选定剧本交给 [directorShots](directorShots.md)，不在剧本阶段擅自启动媒体生成。
